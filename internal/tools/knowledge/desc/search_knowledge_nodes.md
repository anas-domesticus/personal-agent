Find current knowledge nodes by semantic similarity to their titles and descriptions.

Query with the meaning you want to find. Optionally set kind to objective, workflow, claim, source or agent to restrict results to that predefined kind. Limit defaults to 10 and is capped at 100.

Results are ranked by the closer of each node's title and description vectors and include the current node and its similarity score. Search is unavailable when no embedding model is configured.
